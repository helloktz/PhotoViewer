# Contributing to Photo Viewer

Build on Windows 11 x64 using the instructions in [README.md](README.md). For bug reports, include the app version, Windows build, steps to reproduce, and a sample image if possible. English strings live in `Lang.cs` and the Simplified Chinese pack is `source/__assets/__app/_lang/zh-CN.iglang.json`.

Photo Viewer source contributions are distributed under the repository's GPLv3 license.
