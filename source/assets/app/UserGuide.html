Photo Viewer

简体中文 English

使用指南

Photo Viewer 是适用于 Windows 11 的本地图片查看器。你可以浏览同一文件夹中的图片、播放幻灯片、做简单编辑，也可以打印或导出 PDF。

打开与浏览

按 Ctrl+O 打开一张图片，按 ← 或 → 切换上一张或下一张。打开「布局 → 相册面板」即可通过缩略图挑选图片。

用「缩放」菜单切换实际大小或适应窗口。按 F11 切换全屏，或从主菜单启动「幻灯片」。

裁剪、调整大小和取色

  • 在「工具」菜单选择「裁剪图像」，框选要保留的区域。用「另存为」保留原图。
  • 选择「调整图像大小」修改像素尺寸。只想放大查看细节时，可以用「缩放」。
  • 选择「取色工具」查看和复制像素的颜色值，或使用「HDR 色调映射」调整 HDR 图像的显示效果。

打印与导出

按 Ctrl+P 打开打印窗口。可以预览并调整布局，选择打印机或点击「另存为 PDF」。

语言与快捷键

在「设置 → 语言」切换界面语言，在「设置 → 热键」查看或修改快捷键。

User Guide

Photo Viewer is a local image viewer for Windows 11. Browse images in a folder, play a slideshow, make simple edits, and print or export to PDF.

Open and browse images

Press Ctrl+O to open an image. Use ← and → to move between images in the same folder. Open Layout → Gallery panel to browse thumbnails.

Use the Zoom menu to view an image at actual size or fit it to the window. Press F11 for full screen, or choose Slideshow from the main menu.

Crop, resize, and pick colors

  • Choose Tools → Crop image and select the area you want to keep. Use Save as to keep the original file.
  • Choose Tools → Resize image to change the pixel dimensions. Use Zoom if you just want a closer look.
  • Use Color picker to inspect and copy pixel color values, or use HDR tone mapper to adjust how an HDR image appears.

Print and export

Press Ctrl+P to open the print window. Preview and adjust the layout, then choose a printer or select Save as PDF.

Language and keyboard shortcuts

Use Settings → Language to change the display language. Open Settings → Keyboard to view or change shortcuts.
